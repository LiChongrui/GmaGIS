# GmaGIS 使用手册

GmaGIS 是一款桌面地理信息系统，用来**看数据、改数据、算数据**。
本手册按"从打开软件到完成分析"的顺序组织，每一节都可以独立查阅。

---

## 1. 快速上手

1. **看数据** → 「地图」页 → 「添加数据」→ 选文件（Shapefile / GeoPackage /
   GeoJSON / GeoTIFF…）。也可以直接点「一键示例数据」先随便看看。
2. **动数据** → 选中图层 → 「编辑」页 → 「开始编辑」→ 用「要素编辑」「折点编辑」
   改形状，改完点「保存」。
3. **算数据** → 「分析」页 → 「处理工具箱」→ 双击算法（缓冲区 / 相交 / 裁剪…）。
4. **出图**：布局设计器正在优化，暂不可用。

> 编辑操作可撤销：`Ctrl+Z` 撤销、`Ctrl+Y` 重做。改坏了先撤销，别急着关窗口。
> 图层操作（显隐、删除、排序）的撤销 / 重做走「编辑」页里的对应按钮，没有快捷键。

## 2. 界面总览

| 区域 | 作用 |
|---|---|
| **标题栏** | 左侧=应用图标 / 快速访问按钮 / 工程名；中部=功能搜索；右侧=窗口控制 |
| **功能区（Ribbon）** | 按任务分页签：地图 / 编辑 / 分析 / 出图（暂不可用）/ 视图 / 帮助 |
| **画布** | 地图主视图，滚轮缩放、按住拖动平移 |
| **左侧面板** | 图层（图层树 + 图例）、浏览器（文件系统与数据源） |
| **右侧面板** | 识别结果、鹰眼图、处理工具箱、选择统计、日志等，以页签并排 |
| **底部面板** | 属性表 |
| **状态栏** | 坐标、比例尺、当前工具提示、消息条 |

### 功能搜索

标题栏中部的搜索框（`Ctrl+K`）能搜**任何**功能——包括工具箱里的算法。
想不起按钮在哪就敲名字。

### 功能区按钮的三种形态

* **大图标按钮**：一行一个，点一下直接执行；
* **带下拉的大按钮**：点图标执行当前项，点下方箭头展开菜单选别的；
* **小图标按钮**：按列排布，每列最多 3 个，不足时顶部对齐。

## 3. 工程

| 操作 | 入口 |
|---|---|
| 新建工程 | 标题栏左侧工程名 → 新建，或 `Ctrl+Shift+N` |
| 打开工程 | `Ctrl+O`，文件后缀 `.ggis` / `.ggsproj` |
| 保存 / 另存为 | `Ctrl+S` / `Ctrl+Shift+S` |
| 工程属性 | 「视图」页 → 「页面」→ 工程属性（标题、工程坐标系） |

**工程概况**：点标题栏左侧的**工程名**可以查看当前工程概况——工程名、
**视图统计**（地图 / 布局 / 模型各几个）与**最近保存时间**，纯展示、无菜单项。
布局与模型视图正在优化，新入口会给出提示；已有工程里的这两类视图仍会随工程恢复。

工程文件是**纯文本 JSON**，只记数据源路径、显示状态与样式，图层数据仍在
外部文件里——所以工程文件很小，改样式不会重写数据，也方便用文本编辑器排查。

**内存图层**（用「新建形状」直接画出来的那种）没有外部文件，它的要素会
**内嵌进工程文件**：保存工程 = 数据也不丢，不需要单独存一份 shp。

## 4. 数据

### 添加

* 「地图」页 → 「添加数据」→ 选文件 / 从路径添加 / 从数据库添加；
* 「添加矢量」「添加栅格」可添加单类数据；
* 支持拖拽文件到画布。

### 支持的格式

矢量：Shapefile、GeoPackage、GeoJSON、FlatGeobuf、GML、KML、MapInfo TAB、
SQLite/SpatiaLite、Excel CSV。
栅格：GeoTIFF、PNG/JPG（带世界文件）、IMG、VRT 等 GDAL 能读的全部格式。

### 新建

* 「新建」组 → 「新建文件」：建一个 Shapefile / GeoPackage / GDB；
* 「新建」组 → 「新建形状」：直接在内存里建一个点 / 线 / 面图层并开始画，
  画完随工程一起保存，**不需要单独存文件**；
* 新建后会自动跳到「编辑」页签，方便接着改。

### 导出

选中图层 → 右键 → 「导出矢量图层…」/「导出栅格…」，可选格式与创建选项。

## 5. 图层与符号化

* **显隐**：图层树里的复选框；
* **排序**：拖动图层，越靠上越先绘制（压住下面的）；
* **分组**：「新建组」，再把图层拖进去；
* **缩放至图层**：右键 → 缩放至图层；
* **属性**：右键 → 图层属性；
* **符号化**：双击图层，或右键 → 符号化，打开符号设置窗口。

### 图例

图层树下每个图层都带一行（栅格是多行）**图例**：

* 矢量图例画的是与地图上**真实一致**的符号——点画圆、线画线、面画方块，
  颜色 / 描边 / 线宽都跟着符号设置走，分类与分级会逐类列出；
* 栅格图例是一条**颜色条**，顶部标最大值、底部标最小值，中间写明渲染方式
  （单波段灰度 / 单波段伪彩 / 多波段 RGB 合成）。

---

## 6. 标注

选中图层 → 「标注」组：

* **显示字段**：选一个字段作为标注内容；
* **表达式**：用表达式拼多字段、加前后缀；
* **字号 / 颜色 / 描边 / 缓冲区**：控制标注外观；
* **压盖避让**：自动把互相压住的标注推开或省略。

---

## 7. 编辑

### 开始编辑

选中一个矢量图层 → 「编辑」页 → 「开始编辑」。编辑会话打开后，其余编辑
按钮才会亮起（这是有意设计：避免误改）。

### 要素编辑

* **创建**：在地图上依次点出顶点，右键 / 双击结束；
* **移动**：拖住要素整体平移；
* **删除**：点中要素删除。

### 折点编辑

* **编辑折点**：显示所有折点，拖动改形状；
* **选择折点**：下拉里有「矩形」「套索」两种框选方式；
* **添加 / 移动 / 删除折点**：对已选中的折点生效。

### 几何操作

分割、修整、融合、合并、拆分多部件、对齐、打断、概化。

### 捕捉

捕捉是**互斥单选**：端点 / 节点 / 交点 / 中点 / 边，一次只用一类；不选任何
一类就是关闭捕捉。打开后鼠标落点会吸附到几何的指定部位，画精确图形必备。

### 保存与撤销

* **保存**：把编辑写回数据源（内存图层则留在内存，随工程保存）；
* **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`，开关编辑会话前会提醒有未保存的改动。

---

## 8. 选择与查询

* **矩形 / 多边形 / 套索 / 圆形 / 线**：五种框选方式；
* **按属性选择**：写表达式选（如 `"面积" > 1000`）；
* **按位置选择**：与另一图层的要素做空间关系筛选；
* **清除选择 / 选择统计**：清空，或统计选中要素的数量、字段汇总。

选中后「缩放至选择」可把视野对准选中的要素。

---

## 9. 测量

「地图」页 → 「测量」，弹出浮动窗口：

* **测量距离**：逐点点出折线，右键 / 双击结束。结果给**沿线累计长度**，
  并附带**起点到终点的直线距离**（两者差得多说明路径绕）；
* **测量面积**：逐点点出多边形，结果给**面积**与**多边形周长**；
* **测量角度**：依次点三个点，给出夹角与两条边的方位角。

浮动窗口**只显示最终结果**，不记录中间过程；勾选「在地图上实时显示结果」
可把结果同时画在画布上。

## 10. 空间分析

「分析」页 → 「处理工具箱」（或直接双击算法名）。

### 矢量分析

缓冲区、相交、联合、擦除、对称差、标识、裁剪、融合、凸包、包络矩形、质心。

### 矢量处理

修复几何、多部件转单部件、要素去重、简化几何、加密几何、坐标取整。

### 度量与空间关系（方法可复选）

* **度量字段**：勾选面积 / 长度 / 周长 / 顶点数 / 部件数 / 环数 / 最小间隙 /
  圆度中的若干项，**一次运行加多列**（几何不变，只加字段）；
* **空间关系字段**：勾选相交 / 包含 / 内含于 / 相接 / 叠置 / 穿越 / 分离 /
  相等 / 覆盖 / 被覆盖 / 距离内 / 最近距离中的若干项，选好**叠加图层**后
  一趟算出全部勾选字段。

### 栅格分析

工具箱里的栅格算法分三组：

* **地形分析**：坡度、坡向、山体阴影、等高线（矢量输出）；
* **栅格处理**：裁剪栅格（矢量掩模与范围二选一，范围支持"图层自身范围 /
  自定义矩形"）、**影像镶嵌**（多选栅格拼成一幅，先到先得 / 后层覆盖 /
  均值 / 最大值）、**波段合成**（多栅格堆成一个多波段影像）、重采样、波段提取；
* **栅格代数**：栅格计算器（`b1 + b2` 这类表达式）、重分类、归一化、栅格转面。

### 算法对话框怎么用

* **输入图层**：默认从工程里选，点右边的「打开文件」可直接挑磁盘上的文件；
* **叠加图层 / 掩模**：只有需要的算法才出现（如裁剪栅格的掩模是**可选**的）；
* **多选输入**：影像镶嵌 / 波段合成用勾选清单一次挑多个栅格（也可从文件加）；
* **参数**：每个算法只显示它真正用到的参数；
* **输出**：「写入内存」或「写入文件」二选一；
  * 选「写入内存」时，格式 / 输出文件 / 创建选项会**整行收掉**（用不到）；
  * 选「写入文件」时可选格式并指定创建选项（编码 / 空间索引 / RFC 7946…）；
* **将结果加入到地图**：运行按钮左边，默认勾选——写文件的同时也能把结果
  留一份在地图里；
* **进度与取消**：运行时显示进度条与阶段说明，随时可以取消；关掉对话框
  任务还会在**任务面板**里继续跑，双击条目可以找回窗口。

## 11. 制图出图

布局视图正在优化，暂不可用；模型管理器视图同样在优化中。新建布局与
布局设计器入口会给出提示，不创建视图。已有工程里的布局仍会随工程恢复。

「出图」页的导出 PDF / 图片与打印都依赖当前布局，优化完成前不使用。

---

## 12. 设置

「视图」页 → 「设置」（或菜单「设置」→「选项」）：

* **主题**：深色 / 浅色；
* **语言**：简体中文 / English；
* **界面缩放**：跟随系统或 100% / 125% / 150% / 175% / 200%——
  **确定后立即生效**，不需要重启；
* **画布底色**、**canvas 抗锯齿**、**默认临时图层格式**、**消息级别**等。

## 13. 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+Shift+N` | 新建工程 |
| `Ctrl+O` / `Ctrl+S` | 打开 / 保存工程 |
| `Ctrl+Shift+S` | 工程另存为 |
| `Ctrl+Shift+P` | 工程属性 |
| `Ctrl+Q` | 退出程序 |
| `F1` / `Ctrl+F1` | 使用手册 / 快捷键速查表 |
| `Ctrl+K` | 聚焦功能搜索 |
| `Ctrl+Alt+T` | 处理工具箱 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做编辑操作 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴图层 |
| `Ctrl+.` / `Ctrl+Alt+M` | 创建要素 / 移动要素 |
| 滚轮 / 中键拖动 | 缩放 / 平移 |
| `Shift` + 拖动 | 框选缩放 |
| `Esc` | 取消当前工具 / 清除测量 |
| `Backspace` | 测量时退掉上一个点 |
| `Delete` | 编辑时删除选中要素 |

完整列表见「帮助」页 → 「快捷键」（速查表直接列出功能区里所有已登记的快捷键）。
